# Version Control

- A system that tracks, organizes, and manages changes to files and source code over time.

## General Git Commands

- `git init` — initialize a new Git repository in the current folder
- `git status` — check modified, staged, and untracked files
- `git add <file-name>` — stage a specific file
- `git add .` — stage all changes in the project
- `git commit -m "message"` — save staged changes with a commit message
- `git log` — view the commit history
- `git diff` — show changes between working directory and staging area
- `git checkout <branch-name>` — switch to an existing branch
- `git branch` — list branches in the repository
- `git branch -d <branch-name>` — delete a merged branch
- `git reset --hard HEAD` — discard all local changes and reset to the latest commit
- `git stash` — temporarily save changes without committing
- `git stash pop` — restore stashed changes


## Commands for GitHub

- `git config --global user.name "Your Name"` — set your Git username
- `git config --global user.email "you@example.com"` — set your Git email
- `git clone <repository-url>` — copy a GitHub repository locally
- `git status` — show current changes
- `git add .` — stage all changes
- `git commit -m "message"` — save staged changes
- `git push origin <branch-name>` — upload commits to GitHub
- `git pull origin <branch-name>` — fetch and merge remote changes
- `git branch` — list branches
- `git checkout -b <new-branch>` — create and switch to a new branch
- `git merge <branch-name>` — merge a branch into current branch
